# 🔥 Fire Fighting Robot

## Overview

The **Fire Fighting Robot** is an autonomous robotic system developed to detect and extinguish fire with minimal human intervention. The robot integrates flame and smoke detection, obstacle avoidance, and an automatic water spraying mechanism to improve safety in hazardous environments.

## Key Features

* Automatic flame and smoke detection
* Autonomous navigation
* Obstacle avoidance using an ultrasonic sensor
* Automatic water pump activation
* Real-time system monitoring
* Reliable and cost-effective design

## Hardware Components

* Arduino Mega 2560
* L298N Motor Driver
* DC Motors
* Flame Sensor
* Smoke Sensor
* Ultrasonic Sensor (HC-SR04)
* Servo Motor
* Water Pump
* Relay Module
* Buzzer
* Battery Pack

## Software

* Arduino IDE
* Embedded C/C++

## Working

The robot continuously monitors its surroundings using flame and smoke sensors. When a fire is detected, it autonomously navigates toward the source while avoiding obstacles. A servo-controlled water nozzle is positioned toward the flame, and the water pump is activated to extinguish the fire. Once the fire is suppressed, the robot resumes monitoring for additional fire hazards.
