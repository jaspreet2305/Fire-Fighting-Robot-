# Fire-Fighting-Robot-
A Fire Fighting Robot is an intelligent robot designed to detect and extinguish fires. It uses flame and smoke sensors to locate fire, moves toward it using DC motors, and activates a water pump to control the fire. It improves safety by reducing human risk and protecting lives and property.
